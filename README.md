# Credit Card Customer Segmentation

Proyek segmentasi pelanggan kartu kredit menggunakan teknik *unsupervised learning* (clustering) untuk mengelompokkan pelanggan berdasarkan pola transaksi dan perilaku finansial mereka.

## Isi Repository
- `P1G6_Set_1_fawwaz_rifat.ipynb` — notebook lengkap berisi eksplorasi data, pra-pemrosesan, penerapan algoritma clustering, dan interpretasi hasil segmentasi.

## Metodologi
Notebook ini melakukan analisis eksploratif data pelanggan kartu kredit, standardisasi fitur, penentuan jumlah cluster optimal (misalnya menggunakan elbow method/silhouette score), serta penerapan algoritma clustering seperti K-Means untuk membentuk segmen pelanggan.

## Cara Menjalankan
1. Clone repository ini.
2. Buka `P1G6_Set_1_fawwaz_rifat.ipynb` di Jupyter Notebook/Google Colab.
3. Jalankan seluruh sel secara berurutan untuk mereproduksi hasil segmentasi pelanggan.
